# 04 — Konten Materi Pola Bilangan

> Sesuaikan dengan buku siswa yang dipakai sekolah mitra dan Capaian Pembelajaran Matematika Fase D (Kurikulum Merdeka) yang berlaku. Mintalah validasi isi dari dosen pembimbing atau guru matematika.

## 1. Capaian dan Tujuan Pembelajaran

**Capaian Pembelajaran (Fase D, elemen Aljabar)**, ringkasan yang relevan: peserta didik dapat mengenali, memprediksi, dan menggeneralisasi pola dalam bentuk susunan benda dan bilangan.

**Tujuan Pembelajaran (TP) aplikasi:**

| Kode | Tujuan pembelajaran |
|---|---|
| TP1 | Siswa dapat menentukan suku berikutnya dari suatu pola bilangan dengan mengamati selisih antarsuku |
| TP2 | Siswa dapat mengenali pola bilangan khusus (ganjil, genap, persegi, persegi panjang, segitiga, Fibonacci) dari susunan benda |
| TP3 | Siswa dapat menyatakan aturan pola dalam kata-kata dan dalam rumus suku ke-n |
| TP4 | Siswa dapat menentukan suku ke-n menggunakan rumus |
| TP5 | Siswa dapat memeriksa kebenaran aturan pola yang ditemukan |
| TP6 | Siswa dapat menyelesaikan masalah kontekstual yang berkaitan dengan pola bilangan |
| TP7 | Siswa dapat merumuskan situasi nyata ke dalam bentuk barisan, tabel, atau gambar pola (literasi: merumuskan) |
| TP8 | Siswa dapat menafsirkan hasil perhitungan pola dalam konteks dan menilai kewajarannya (literasi: menafsirkan) |
| TP9 | Siswa dapat menilai kebenaran suatu klaim tentang pola dan memberikan alasan (literasi: penalaran) |

## 2. Peta Materi (Modul)

| Modul | Subtopik | TP | Visual utama |
|---|---|---|---|
| M0 | **Pengingat Prasyarat**: barisan, suku, urutan, selisih; operasi hitung dasar | — | Kartu bernomor berjajar |
| M1 | **Mengenal Pola**: pola pada benda/gambar, suku berikutnya | TP1 | Susunan benda (ubin, noktah) |
| M2 | **Pola dengan Selisih Tetap**: lompatan sama | TP1, TP3 | Garis bilangan + panah lompatan |
| M3 | **Pola Bilangan Khusus (1)**: ganjil (2n − 1), genap (2n) | TP2, TP3 | Noktah berpasangan |
| M4 | **Pola Bilangan Khusus (2)**: persegi (n²), persegi panjang (n(n + 1)) | TP2, TP3 | Noktah berbentuk persegi/persegi panjang |
| M5 | **Pola Bilangan Khusus (3)**: segitiga (n(n + 1)/2) | TP2, TP3 | Noktah berbentuk segitiga |
| M6 | **Pola Fibonacci**: suku = jumlah dua suku sebelumnya | TP2 | Tabel dua suku sebelumnya |
| M7 | **Menentukan Suku ke-n**: dari aturan ke rumus (an + b), selisih tingkat dua (pengayaan) | TP3, TP4, TP5 | Tabel n vs Un |
| M8 | **Literasi: Memecahkan Masalah dengan Pola**: stimulus campuran (personal, sosial-budaya, saintifik), soal penalaran dan pengambilan keputusan, siklus mandiri (tahap C) | TP6–TP9 | Stimulus bergaya AKM |

Urutan ini mengikuti prinsip **sederhana → kompleks** untuk mengelola beban intrinsik.

**Literasi di setiap modul:** modul M1–M7 masing-masing ditutup dengan **1 stimulus kontekstual (3–4 soal L1→L3)** yang memakai pola modul tersebut, misalnya M4 dengan Motif Batik Kawung dan M5 dengan Tumpukan Kaleng di Warung. M8 menjadi puncak: konteks campuran, siswa harus memilih sendiri jenis polanya, dan bantuan siklus sudah minimal. Detail di `11-literasi-matematika.md`.

## 3. Tes Awal (Diagnostik) — Draf

| No | Soal | Prasyarat yang diukur |
|---|---|---|
| 1 | Tentukan bilangan berikutnya: 2, 4, 6, 8, … | Selisih tetap |
| 2 | Berapa selisih antara 7 dan 12? | Operasi selisih |
| 3 | Tentukan bilangan berikutnya: 1, 4, 9, 16, … | Bilangan kuadrat |
| 4 | Gambar noktah berbentuk segitiga 1, 3, 6. Berapa noktah berikutnya? | Pola gambar |
| 5 | Tentukan bilangan berikutnya: 1, 1, 2, 3, 5, … | Fibonacci |
| 6 | Jika aturan pola "kalikan urutannya dengan 4", berapa suku ke-5? | Membaca aturan |

Rekomendasi: skor 0–2 → mulai dari M0; skor 3–4 → mulai dari M2; skor 5–6 → boleh langsung ke M7 (expertise reversal).

## 4. Contoh Bank Soal per Modul

Setiap soal di bank soal memiliki: teks soal, representasi visual, jawaban, 3 petunjuk, umpan balik untuk 2–3 kesalahan umum, dan tingkat kesulitan (1–3).

### M2 — Pola dengan Selisih Tetap
1. (1) 5, 8, 11, 14, … Tentukan 2 suku berikutnya.
2. (2) 2, 6, 10, 14, … Tentukan suku ke-8.
3. (2) Lengkapi: 7, …, 17, 22, …
4. (3) 1, 4, 7, 10, 13, … Tentukan rumus suku ke-n dan periksa untuk n = 3.

### M3–M5 — Pola Khusus
1. (1) Gambar noktah 1, 3, 5, 7. Berapa noktah pada gambar ke-6?
2. (2) Pola persegi 1, 4, 9, 16, … Tentukan suku ke-12.
3. (2) Pola persegi panjang 2, 6, 12, 20, … Tentukan suku ke-7.
4. (3) Pola segitiga 1, 3, 6, 10, … Tentukan suku ke-10.

### M6 — Fibonacci
1. (1) 1, 1, 2, 3, 5, 8, … Tentukan suku berikutnya.
2. (2) 2, 3, 5, 8, 13, … Tentukan 2 suku berikutnya.

### M7 — Suku ke-n
1. (2) Pola 4, 7, 10, 13, … Rumus suku ke-n adalah … (pilihan: 3n + 1, n + 3, 4n, 3n + 4)
2. (3) Pola 2, 6, 12, 20, … Tentukan rumus suku ke-n.

### M8 — Literasi (contoh, label: level · proses)
1. (L2 · LM2, LM3) Baris pertama gedung pertunjukan berisi 10 kursi. Setiap baris berikutnya bertambah 2 kursi. Berapa kursi pada baris ke-15?
2. (L2 · LM2) Susunan ubin: gambar 1 memakai 1×2 ubin, gambar 2 memakai 2×3 ubin, gambar 3 memakai 3×4 ubin. Berapa ubin pada gambar ke-8?
3. (L3 · LM6) **Menjodohkan + alasan:** Jodohkan tiga cerita (meja hajatan, tabungan, tumpukan kaleng) dengan barisannya, lalu pilih alasan mengapa tumpukan kaleng bukan pola selisih tetap.
4. (L3 · LM4, LM5) Dina menabung Rp5.000 pada minggu pertama dan menambah Rp2.000 setiap minggu. Ia ingin menabung Rp35.000 dalam satu minggu. Pada minggu ke berapa hal itu terjadi? Apakah jawabanmu masuk akal? *(5.000 + 2.000(n − 1) = 35.000 → n = 16)*
5. (L3 · LM6) **Benar/Salah:** "Pola meja hajatan 4, 6, 8, … pasti akan mencapai 101 kursi." Benar atau salah? Jelaskan. *(Salah. Semua suku genap, jadi tidak mungkin 101.)*

Contoh stimulus lengkap "Kursi Lomba 17 Agustus" ada di `11-literasi-matematika.md` bagian 7.
